# 先证伪 / Falsify First

在你把钱放上去之前，把这个想法杀掉。

否掉一个策略的成本是两个小时。试错的成本是一个账户。

大多数人亏钱不是因为找不到机会，是因为从来没有认真试图否掉自己那个想法：他们只找证据支持它。这个仓库给的是判据，不是策略。

## 这是什么

一个 Agent Skill，由 `SKILL.md` 和 `references/` 组成。纯 Markdown，零脚本，不联网、不需要数据接口、不需要任何账号。输入是你自己的回测结果，或者纸上一个还没跑的想法。

它不给策略、不选股、不预测某个标的。全部产出是否定性的：什么不成立、为什么不成立、下次别在哪摔。

## 一条能翻转结论的坑

这一条是整套流程里最值钱的。

一套信号，单笔 +0.330%、胜率 42.4%、盈亏比 1.46、平均持有 16.4 天，全程正数。看着可以考虑。

但它的信号扎堆在市场暴跌后的反弹日。那些日子全市场都在涨，用全期日均去比，等于拿自己的表现跟一个平常日比。按信号日匹配、取同池 20 日基准，那些日子的基准是 +1.087%，而全期日均只有 +0.151%。

| 基准口径 | 超额 |
|---|---|
| 全期日均（错） | +0.18 pp |
| 信号日匹配、同池 20 日（对） | **−0.757 pp** |

同一个策略，同一个样本，从「可以考虑」变成「明确为负」，只因为换了分母。这类错误在绝大多数回测报告里都没被纠正过。

## 十道否定线

| # | 判据 | 门槛 |
|---|---|---|
| 1 | 单笔净超额（扣费用与滑点） | > 0 |
| 2 | 分两段同号为正 | 两段都 > 0 |
| 3 | 分年度为正的比例 | ≥ 5/6 |
| 4 | 独立块 t（按块算，不是按单笔） | ≥ 1.3 |
| 5 | 加 0.1% 单边滑点仍为正 | > 0 |
| 6 | 样本量 | ≥ 500 笔 |

六条里过四条才有资格进下一步。过三条以下直接停，别调参数。

余下四条是流程，不是门槛：

- **基准按信号日匹配**，且与持仓周期同口径。开盘买就开盘起算，尾盘买就尾盘起算，两者差 0.1 到 0.2 个百分点，足够把结论翻过来。
- **逐条剥离归因**。保留全套作基准，每次只去掉一个条件重跑，看谁在拖后腿。全部变体都为负，说明不是条件组合的问题，是逻辑本身不成立。
- **失败分三层**。参数性失败可以调（但试了二十组参数总有一组正，那是多重比较）；结构性失败换方向也没用；制度性失败是收益存在但你执行不了。
- **横截面极端组检查**。如果你总在选涨幅最大、跌幅最深、换手最高的，先看分组收益的形状。真实样本里是倒 U，中间组小幅跑赢，第 10 组最惨，t 值 −7 到 −9。

## 阈值怎么来的

不是拍的。下面这些数字全部来自一套真实执行的策略，五年多、6060 笔、三次方向全败：

- 胜率 39.5%，单笔均 −0.085%，盈亏比 1.47，最长连亏 43 笔，独立块 t −0.22
- 三次换方向（动量 → 回调 → 反转）结论完全一致，最后定位到结构而非参数
- 横截面倒 U，第 10 组多空 −1.21 到 −2.14 pp，t −7.1 到 −8.9
- 制度性不可执行一例：某类信号次日 +0.514 pp，改成符合 T+1 的次日卖出后变 −0.335 pp
- 仓位不是解药：本金 5 万亏 33.17%，放大到 20 万亏 28.48%，本金 4 倍、绝对亏损 3.4 倍，单笔收益率与胜率一个数字没变

这些阈值是「便宜」，不是「苛刻」。花两小时否掉一个想法，比花两万块试它便宜。

## 怎么用

1. 填预注册表（`references/prereg.md`），六条判据写死，标日期。跑完一个字不许改，改一条这次回测就作废。
2. 跑。跑完先看六条过了几条，**不要先看总收益**。
3. 过四条以上，再做归因与横截面检查（`references/attribution.md`），确认没有隐藏的极端组、没有制度性不可执行的漏洞。
4. 全部通过再谈用真钱试，而且只用你能承受全部损失的那部分。

## 文件

```
SKILL.md                    主判据（十块，全部在正文，离线可读）
references/prereg.md        预注册表模板 + 六条门槛的判定细则
references/attribution.md   归因口径、块 t 算法、横截面分组检查
references/postmortem.md    三次真实失败的完整复盘
```

`postmortem.md` 里写了每一步是怎么发现问题的、哪些数字在**当时看起来是好消息**。这部分是同类材料里最少见的，也是这个仓库真正的价值所在。

## 安装

这是 Agent Skill 格式，把整个目录放进你的 skills 目录即可，不需要安装任何依赖：

```bash
git clone https://github.com/PeterPan118/falsify-first.git ~/.workbuddy/skills/falsify-first
```

然后在对话里说「我这个策略回测是正的，帮我看看能不能上」「跑了六千笔单笔还是负的，是不是参数没调好」「亏了三个月了，什么时候该停」，它会走上面的流程。

单独读也能用。`SKILL.md` 是一篇完整的判据文档，不依赖任何运行时。
